# Vietnam Flood

Vietnam Flood is a free community dashboard that brings together rainfall, river and reservoir observations, forecasts, and official flood bulletins across 21 provinces and cities in Vietnam.

[Open the dashboard](https://vietnamflood.io.vn/)
